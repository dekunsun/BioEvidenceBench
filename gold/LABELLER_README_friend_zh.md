# 第二位标注员：先看这里

谢谢你帮忙！这个项目评测大模型能不能从 19 世纪的博物学书页里正确找出学名、俗名、人名、地名、机构名和日期。你标的 5 页用来检查标注规范写得够不够清楚：两个人各自按同一份规范标，比较结果。**所以最重要的一条是：独立标。**

## 三条规则

1. **只看这个文件夹里的东西。** 不要看 Gloria 的标注，不要打开项目的 GitHub 仓库（里面有她的标注和讨论记录）。
2. **不要用 AI 助手**（ChatGPT、Claude、Gemini 等）帮忙判断或检查。被评测的就是这些模型，用了它们，比较就不独立了。查词典、查地图、查 Avibase 之类的参考资料都可以。
3. **拿不准的不要问 Gloria，按规范的意思做最好的判断**，在 `notes` 里写 `UNCLEAR:` 加原因。拿不准本身就是有用的结果，说明规范那里没写清楚。

## 包里有什么

| 文件 | 用途 |
|---|---|
| `ANNOTATION_GUIDE_标注员版_v0.10.md` | 标注规范 v0.10。中文版在文件后半部分。第 3 节（学名关联）你不用做 |
| `页面清单.csv` | 5 页的清单，最后一列是扫描图链接 |
| `页面/` | 5 页的文字（专家转录）。每行开头的数字是这一行第一个字符的位置 |
| `表格/gold_mentions_friend.csv` | **主要的标注表**：每个提及一行，只有表头 |
| `表格/annotation_issues_friend.csv` | 名字被无关文字隔开时记在这里（规范 2.0.3），一般用不到 |

## 怎么标

1. 先读一遍规范（第 0–2 节和第 4 节开头）。
2. 一页一页标。打开文字文件，同时打开扫描图链接对照版式（标题、页眉、图注在扫描图上看得最清楚）。
3. 在 `gold_mentions_friend.csv` 里每个提及写一行。六种字段：`taxon`（学名）、`vernacular`（俗名）、`person`（人）、`locality`（地点）、`institution`（机构）、`date`（事件日期）。
4. **位置可以不填。** 只填 `page_id`、`field` 和 `text`（从文字文件里原样复制，不要改拼写），`start` 和 `end` 留空，之后用脚本自动算。
5. `guide_version` 都填 `v0.10`。`adjudication` 留空。
6. 文字文件和扫描图不一致时：`text` 照文字文件抄，扫描图上的读法填进 `scan_text`，`notes` 写 `TRANSCRIPTION-ERROR`。
7. 一页上一个提及都没有时，也写一行：`field` 填 `none`。

## 几条最容易出错的规则

- 片段末尾的句点：缩写后面保留（`Linn.`），完整的词后面去掉。
- 头衔不算进人名：`Lord Lilford` 标 `Lilford`。
- `near Dover`：片段是 `Dover`，`near` 填进 `qualifier` 列。
- 条目开头的标题要标；每页重复的页眉、`PLATE XLV.` 这种图版编号不标。
- 引用里的年份（`Pro. Zool. Soc., 1846`）不是 `date`。
- 跨行断开的名字标成一个片段。

## 标完以后

把两个表格（标注问题表没内容也一起）**原样**发给 Gloria。发出之前不要和任何人对比。之后会逐条比较两个人的结果，分歧由 Gloria 裁定。

# Poster

Portrait **A1 (594 × 841 mm)**, one page, for Deep Matters 2026 (Agents for Science, 26 November 2026). Version 5 (2026-11-25, the author: v4 had too much text and the large yellow scans looked busy; "之前你做的 livelab 就挺好的"): the LiveLab poster's layout and stylesheet (copied from `dekunsun/livelab/poster/poster.html` by the builder), BioEvidenceBench content. `poster.html` is generated by `src/build_poster_v5.py` (do not edit by hand); charts by `src/plot_poster_v5.py` → `fig/v5/`; scans shown small and in grey (`fig/v5/*_grey.png`). Final print version (2026-11-25): title "From historical page to database record: where do AI agents lose evidence?"; header with the BioEvidenceBench kicker, key finding, and the Penn logo above the repository QR. Rows: 01 Motivation (grey BULIMUS scan and shell; printed → library OCR → what the database needs; five steps, read and link in red) | 02 Methodology (one page read three ways; "point, not write": the model returns a line and a quote, code verifies the quote and extracts the source value; data strip 16 / 421 / 0.90). 03 Results (three KPI cards, charts A F1 by text, B names intact vs F1, C link recall) | 04 Try it (one quiz question on a real 1849 scan line, answer upside down; classical Chinese 本草綱目 bar chart, exploratory). 05 Proposed Framework ("Model writes the record" against "Code owns the text; the model points, quotes, and defers", each step with its evidence, losses in red) | 06 Conclusion (three rules, scope) and Connect & Explore. Earlier versions kept: `poster_a1_v4.*` (rows, yellow scans), `poster_a1_v3.*` (three columns), `poster_a1_v2.*`, `poster_a1_v1.*`, `poster_a0.*`.

- `poster.html`: the source. Edit this, never the PDF.
- `poster.pdf`: printed from the source with headless Chromium (`node render.js "$PWD" poster A1`), A1. Print at 100 %, no scaling.
- `preview.png`: a half-scale screenshot of the same page.
- `fig/`: the three charts (`extraction_poster.png`, `ladder_poster.png`, `linking_poster.png`) are drawn by
  `src/plot_poster_charts.py` at the width they occupy on the poster, so every label is the body size; values are read
  from the run records. University of Pennsylvania logo (reversed, for the dark band) and the AI4S.fyi logo and QR codes
  are reused from the LiveLab poster; `qr_repo.svg` points to this repository. `cas_logo_reverse.png` is a white copy of the California Academy of Sciences logo, added at the author's request (she volunteers with its Scientific Computing team; the project is independent and uses public data only). The strips `misread_poster.png`, `fluent_poster.png` and `linking_page_poster.png` are cut from the real scans by `src/plot_scan_examples.py` (`poster_strip`, `poster_fluent_strip`, `poster_linking_strip`); `books_poster.png` and `bencao_glyph_poster.png` are README figures 11 and 10 with their title band and footnote cropped off (credits are in the poster captions).

Rebuild after editing the source:

```bash
python src/plot_poster_v5.py
python src/build_poster_v5.py
node poster/render.js "$PWD/poster" poster A1
```

`render.js` prints the height of each row and of the main area; if `main` scrolls past its client height, a row
overflowed and the bottom of the poster is cut. Type: five sizes (80 px title, 52 px numbers, 32 px card titles, 24 px body, 20 px notes); diagram labels are snapped to 24 / 20 px by a script in the page.

# Poster

Portrait **A1 (594 × 841 mm)**, one page, for Deep Matters 2026 (Agents for Science, 26 November 2026). Version 5 (2026-11-25, the author: v4 had too much text and the large yellow scans looked busy; "之前你做的 livelab 就挺好的"): the LiveLab poster's layout and stylesheet (copied from `dekunsun/livelab/poster/poster.html` by the builder), BioEvidenceBench content. `poster.html` is generated by `src/build_poster_v5.py` (do not edit by hand); charts by `src/plot_poster_v5.py` → `fig/v5/`; scans shown small and in grey (`fig/v5/*_grey.png`). Final print version (2026-11-25): title "From historical page to database record: where do AI agents lose evidence?"; header with the BioEvidenceBench kicker, key finding, and the Penn logo above the repository QR. Rows: 01 Motivation (grey BULIMUS scan and shell; printed → library OCR → what the database needs; five steps, read and link in red) | 02 Methodology (one page read three ways; "point, not write": the model returns a line and a quote, code verifies the quote and extracts the source value; data strip 16 / 421 / 0.90). 03 Results (three KPI cards, charts A F1 by text, B names intact vs F1, C link recall) | 04 Try it (one quiz question on a real 1849 scan line, answer upside down; classical Chinese 本草綱目 bar chart, exploratory). 05 Proposed Framework ("Model writes the record" against "Code owns the text; the model points, quotes, and defers", each step with its evidence, losses in red) | 06 Conclusion (three rules, scope) and Connect & Explore. Also kept: `poster_a0.*`, the A0 version made before the board size was confirmed. Earlier A1 drafts (v1–v4) were removed on 2026-11-27 to keep the repository small; they remain in the git history (any commit before that date).

- `poster.html`: generated by `src/build_poster_v5.py`. Edit the builder, never the HTML or the PDF.
- `poster.pdf`: printed from the source with headless Chromium (`node render.js "$PWD" poster A1`), A1. Print at 100 %, no scaling.
- `preview.png`: a half-scale screenshot of the same page.
- `fig/`: `fig/v5/` holds the charts (`f1_by_text.png`, `names_vs_f1.png`, `link_recall.png`, `bencao_bars.png`, drawn by
  `src/plot_poster_v5.py` at the size they print), the grey scans of box 01 and the quiz line of box 04 (`quiz_granulosus.png`,
  cut by `src/build_poster_v5.py` from the bhl-impact-gt page image, CC BY 3.0). `fig/v2/bencao_chars.png` is the 陶弘景 crop
  from the 本草綱目 scan (public domain). University of Pennsylvania logo (reversed, for the dark band), the AI4S.fyi logo and
  the QR codes are reused from the LiveLab poster; `qr_repo.svg` points to this repository. The remaining files in `fig/` are
  used by the A0 version.

Rebuild after editing the source:

```bash
python src/plot_poster_v5.py
python src/build_poster_v5.py
node poster/render.js "$PWD/poster" poster A1
```

`render.js` prints the height of each row and of the main area; if `main` scrolls past its client height, a row
overflowed and the bottom of the poster is cut. Type: five sizes (80 px title, 52 px numbers, 32 px card titles, 24 px body, 20 px notes); diagram labels are snapped to 24 / 20 px by a script in the page.

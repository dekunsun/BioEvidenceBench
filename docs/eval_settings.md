# BioEvidenceBench: evaluation settings

One row per run folder, generated from the run records by `src/make_eval_settings.py`; never edited by hand. A dash means the record does not hold that field. Results: [results](results.md). Plan: [`PREREGISTRATION.md`](../PREREGISTRATION.md); later changes: [`DEVIATIONS.md`](../DEVIATIONS.md).

**Common to every LLM run.** The model never rewrites source text: lines are numbered, the model returns values (G0) or a line plus a verbatim quote (G1, G2), and code slices or checks against the source. Temperature is never set, so each provider's default applies; Claude runs use adaptive thinking with the `effort` shown; Gemini runs use the model's default thinking. Every request and raw response is saved in the run folder, with the prompt, the input text's SHA-256 and the timestamp. Test-page outputs of the pre-registered runs were sealed until the freeze. Batch requests cost half the list price.

**Conditions.** G0 values only; G1 line + verbatim quote (the frozen condition); G1F the frozen G1 prompt word for word on new pages; G2 verbatim quote + a repaired reading; V1 page image only; V2 image + OCR text; V3 image only, with a box per mention.

# Stories from the project

Short pieces about things that happened along the way, in Chinese and English. Each one links
to the records it is based on.

| Story | What happened |
| --- | --- |
| [一个缩写的鸟名，两种鸟 · One abbreviated name, two birds](one_abbreviated_name_two_birds.md) | While labelling Butler's bird names, `M. hyperythra` matched two modern species. The trail ran through Seebohm 1883 and Oates 1890 to a half-sentence Butler had cut: "of Cabanis apud Brooks". |
| [金标准也有错别字 · The gold standard has typos](the_gold_standard_has_typos.md) | The expert transcription read `nontifringilla` and `I898`; 21 of 22 modern OCR models read the scan correctly and would be marked down for it. |
| [API 说"成功"，其实失败了 · When "success" is a failure](when_success_is_a_failure.md) | Gemini's Batch API dropped the output schema without an error; in LiveLab, Gemini Live told the model about a server error instead of the client. Both looked like model behaviour. |
